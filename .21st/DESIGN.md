# SABLE design direction

Phase 1 contains only the transparent header and 100svh film hero.
The user brief is the source of truth: simple wordmark, exact copy, warm cream type,
a thin copper CTA underline, and a restrained editorial serif.
Video uses object-fit: cover with no added scaling. Copy sits at the lower left.
On mobile, navigation remains visible in a quiet second row.
Native CSS handles entrance reveals. Reduced motion stops autoplay and reveals.
The film has a poster fallback and a pause control.
No catalog component was reused; the 21st catalog search was unavailable.
